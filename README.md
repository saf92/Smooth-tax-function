# Smooth-tax-function
Code for non-linear fit of the below smooth tax function in the paper ['On Properties of a Smooth Income Tax Function with Application to the UK'](https://vixra.org/abs/2511.0128).

The smooth tax function with free parameter $\gamma$ is

$$
T(x) = q\left(x - \frac{1}{\gamma}(1 - e^{-\gamma x})\right), \quad \gamma > 0, \quad q \in (0,1).
$$
